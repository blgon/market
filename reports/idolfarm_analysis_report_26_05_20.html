분석 프레임워크

세 지표를 함께 봐야 정확한 소재 평가가 가능합니다.

  • CPI(Net) 단독: 설치만 싸게 만들 수 있는 소재 (D1에 이탈하는 유저일 수 있음)
  • CPR_D1(Net) 단독: 유저 퀄리티는 좋지만 표본이 적을 수 있음 (운빨일 수 있음)
  • Spend: 실제 검증된 규모. Spend가 큰 소재 = 알고리즘이 충분히 노출시킨 = 신뢰 가능
핵심 원칙: 세 지표를 동시 만족할 때 6월 메인 소재로 자격을 부여합니다.

계산식

  • CPI(Net) = Spend ÷ 1.1 ÷ Install
  • CPR_D1(Net) = Spend ÷ 1.1 ÷ D1 Retained User
